# STEPS:
1. download the `.apk`.
2. open the menu (top left) and go to `Custom URL`.
3. enable `Log to custom URL`.
4. set URL to: `https://humbly-rekindle-comment.ngrok-free.dev/api/gps`
5. set HTTP Body to: `["name-here-phone","phone",%LAT,%LON]`
6. set HTTP Method to: `POST`
7. start logging and i'll message you your coords

Much thanks to [mendhak](https://github.com/mendhak/gpslogger/releases) for creating the app.
