# STEPS:
    1. download the `.apk`.
    2. open the menu (top left) and go to `Custom URL`.
    3a. enable `Log to custom URL`.
    3b. set URL to: `https://humbly-rekindle-comment.ngrok-free.dev/api/gps`
    3c. set HTTP Body to: `["name-here-phone","phone",%LAT,%LON]`
    3d. set HTTP Method to: `POST`
    4. start logging and i'll message you your coords
